## 欢迎来到我的个人网站

酝酿许久，终于动手搭建了自己的网站。

### 为什么要建这个网站？

作为一个计算机专业的学生，拥有一个个人网站有很多好处：

- **知识输出**：写博客是整理和巩固知识的最好方式之一
- **个人名片**：简历可以展示，但一个精心打造的网站更能体现你的品味和技术能力
- **实验场**：新技术、新想法都可以在这里实践

### 技术选型

这个网站使用以下技术搭建：

- **Astro**：现代静态站点生成器，零 JS 默认输出
- **Tailwind CSS**：实用优先的 CSS 框架
- **Markdown**：内容以 Markdown 编写，版本管理友好

示例代码：

```ts
export function greeting(name: string): string {
  // 拼接问候语
  const message = `你好，${name}！`;
  return message;
}

const words = greeting("世界");
console.log(words); // "你好，世界！"
```
